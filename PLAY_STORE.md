## Full description — English

PromptForge AI helps you turn a simple idea into a structured prompt tailored to the AI tool you want to use.

Choose the target tool, describe what you want, and PromptForge builds a prompt around the tool's workflow, capabilities, input style, and useful output controls.

### What you can do
• Create prompts from an idea.
• Improve an existing prompt.
• Choose from a broad catalog of AI tools.
• Generate different prompt structures for chat, research, image, video, voice, music, coding, marketing, writing, presentations, design, and 3D workflows.
• Save prompts and keep a local history.
• Use the local prompt engine or connect an optional backend for AI-assisted generation.
• Copy and share generated prompts.

PromptForge AI is not an AI model itself. It is a prompt-generation and prompt-optimization tool designed to help you prepare better inputs for other AI systems.

Some remote-generation features depend on the backend configuration and the availability of the connected AI provider.
